# BoardDocs fetch log - BVSD Board of Education (go.boarddocs.com/co/bvsd)

Retrieved 2026-09-03 (per-file UTC timestamps in MANIFEST_boarddocs.csv). Method: python `requests` with a Chrome User-Agent against the public Lotus Domino endpoints: `BD-GetMeetingsList?open` (POST `current_committee_id=AB2M7659D065`; JSON list of 1037 meetings, 2006-2026), `BD-GetAgenda?open` (POST `id=<meeting id>`), `BD-GetAgendaItem?open` (POST `id=<item id>`), and `BD-GetPublicFiles?open` (POST `id=<item id>`) - the last one is what lists attachments; the item HTML itself only carries an empty `attachment-public-<id>` placeholder. Files were then fetched by GET on the `pfiles/<id>/$file/<name>` URLs. Every agenda of every meeting dated 2015-01-01 or later (957 meetings) was pulled and keyword-indexed (enrollment, trend, long range, LRAC, capacity, boundary, attendance area, resilient, declining, class size, staffing, allocation, projection, closure, consolidation, budget, open enrollment, demographic). Site-wide text search is disabled on this BoardDocs instance (`bd.meta_search_status="Disabled"`), so that index served as the search. Item URLs have the form https://go.boarddocs.com/co/bvsd/Board.nsf/goto?open&id=<item id>.

A CloudFront WAF rate limit (HTTP 403 'Request blocked') triggered after the 4-worker agenda sweep; it cleared after about three minutes and all later requests were made sequentially at one request per 2-3 s. One download batch was interrupted by that block and re-run; the manifest records the successful attempt only.

## Result summary

- PDFs saved: **141** (185.9 MB), each with a sibling `.txt` (pdfplumber text layer; every `.txt` is non-trivial, but slide decks with charts carry only their labels - the capacity/projection tables inside decks may need OCR or reading by eye).
- Byte-identical duplicates skipped (md5 matched a file already in `data/raw/bvsd/` or one saved earlier in this batch): **9** (listed in the manifest with '(not saved)' in the file column).
- Download errors: **0**.
- Agenda-item description text for every item inspected: `AGENDA_ITEM_DESCRIPTIONS.md`.
- Nothing outside `data/raw/bvsd/boarddocs/` was created or modified by this fetch.
